Definición de sensores

Un sensor es un componente que detecta una magnitud física o un cambio en el entorno (movimiento, luz, temperatura, posición, presión, etc.) y lo convierte en una señal que el dispositivo puede leer. Los teléfonos y tabletas incluyen varios sensores que las aplicaciones pueden aprovechar, por ejemplo para girar la pantalla, contar pasos, mostrar un mapa o ajustar el brillo.

Tipos de sensores en dispositivos móviles

Android los agrupa en tres categorías:

Categoría Descripción Sensores y uso
Sensores de movimiento Miden fuerzas de aceleración y rotación en tres ejes (x, y, z).
  • Acelerómetro: aceleración; detectar sacudidas, orientación.
  • Giroscopio: velocidad de rotación; juegos, realidad aumentada.
  • Vector de gravedad y aceleración lineal.
  • Contador de pasos.
Sensores ambientales Miden condiciones del entorno.
  • Luz (iluminación): brillo automático de pantalla.
  • Barómetro (presión): altitud, clima.
  • Temperatura y humedad relativa (no todos los equipos los tienen).
Sensores de posición Determinan la posición física u orientación del dispositivo.
  • Magnetómetro (brújula): campo magnético terrestre; mapas y navegación.
  • Proximidad: apaga la pantalla al acercarlo a la oreja en una llamada.
  • Vector de rotación y orientación.

Además, hay otros componentes que funcionan como sensores aunque no se manejen igual:

  • GPS / ubicación: coordenadas geográficas (se maneja con servicios de ubicación, no con SensorManager).
  • Cámara y micrófono: captan imagen y sonido.
  • Sensor de huellas / biométricos: autenticación.
  • Sensores de comunicación: NFC, Bluetooth, Wi-Fi.

También se clasifican como sensores de hardware (componentes físicos) y sensores de software o virtuales (combinan datos de varios sensores físicos, como la aceleración lineal o el vector de rotación).

Proceso de gestión de sensores

1. Habilitación

  • Verificar que el sensor existe en el dispositivo (no todos tienen todos los sensores).
  • Declarar los permisos necesarios en el AndroidManifest.xml. Por ejemplo, para el contador de pasos se necesita el permiso de reconocimiento de actividad; para ubicación, los permisos de ubicación.
  • Si el permiso es "peligroso", pedirlo al usuario en tiempo de ejecución.
  • Obtener el SensorManager y el sensor deseado.

2. Obtención de información

  • Implementar la interfaz SensorEventListener, con los métodos onSensorChanged() y onAccuracyChanged().
  • Registrar el listener con registerListener() indicando la frecuencia de muestreo (normal, UI, juego, rápida).
  • Los datos llegan en un objeto SensorEvent (por ejemplo, event.values[0], [1], [2]).
  • Cancelar el registro con unregisterListener() cuando la app deja de usarlo (en onPause()) para ahorrar batería.

3. Procesamiento de la información

  • Filtrado: los datos tienen ruido; se usan filtros (por ejemplo, pasa-bajas) para suavizarlos.
  • Conversión: pasar los valores a unidades útiles (grados, m/s², lux).
  • Interpretación: detectar eventos, como una sacudida si la aceleración supera cierto umbral.
  • Uso: mostrar el dato en pantalla, guardarlo o enviarlo a un servidor.
Buena práctica: usar la frecuencia de muestreo más baja que sirva para tu caso, y siempre liberar el sensor cuando no se use.

Ejemplo completo: leer el acelerómetro

class MainActivity : AppCompatActivity(), SensorEventListener {

    private lateinit var sensorManager: SensorManager
    private var acelerometro: Sensor? = null

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        // 1. Habilitación
        sensorManager = getSystemService(SENSOR_SERVICE) as SensorManager
        acelerometro = sensorManager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER)

        if (acelerometro == null) {
            Toast.makeText(this, "No hay acelerómetro", Toast.LENGTH_SHORT).show()
        }
    }

    override fun onResume() {
        super.onResume()
        // 2. Obtención: se registra el listener
        acelerometro?.also {
            sensorManager.registerListener(this, it, SensorManager.SENSOR_DELAY_NORMAL)
        }
    }

    override fun onPause() {
        super.onPause()
        sensorManager.unregisterListener(this)
    }

    override fun onSensorChanged(event: SensorEvent) {
        val x = event.values[0]
        val y = event.values[1]
        val z = event.values[2]

        // 3. Procesamiento: detectar sacudida
        val fuerza = Math.sqrt((x * x + y * y + z * z).toDouble())
        if (fuerza > 20) {
            Log.d("Sensor", "¡Sacudida detectada!")
        }
    }

    override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) { }
}
